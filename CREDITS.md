# Credits

## Assets

This project downloads no 3D models, textures, sounds or images. Everything visual and
audible is made in code or was drawn for this project:

| Asset                                             | Source                                                             | License              |
| ------------------------------------------------- | ------------------------------------------------------------------ | -------------------- |
| Room, furniture, character, cat (3D)              | Built procedurally from three.js primitives in `src/`              | Same as this project |
| Floor planks, code screen, laptop screen textures | Drawn at runtime with Canvas 2D (`src/scene/textures.ts`)          | Same as this project |
| Sound effects                                     | Synthesized at runtime with the Web Audio API (`src/lib/sound.ts`) | Same as this project |
| Placeholder project screenshots, favicon          | Hand-written SVG in `public/`                                      | Same as this project |
| Placeholder résumé                                | Generated one-page PDF in `public/`                                | Same as this project |
| Open Graph image                                  | Screenshot of this site                                            | Same as this project |
| Emoji (icons in UI)                               | Rendered by the visitor's operating system font                    | n/a                  |
